# VGA 1920x1080 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the TUI-OS desktop from an 80x25 VGA text screen into a 1920x1080
linear-framebuffer pixel screen with 16x32 character cells (a 120x33 grid),
keeping the text mode as the graceful-degradation path.

**Architecture:** One ratatui `Backend` with two sinks. `draw()` already receives
only the cells ratatui's diff changed, so the pixel sink rasterizes a glyph per
changed cell and the existing diffing is untouched. Mode selection goes through
a V86 monitor that calls VBE `int 10h` at boot, because the boot chain cannot
supply a 1080p mode (spec fact 3). The 8x16 CP437 font is located by scanning
the VGA BIOS ROM and doubled to 16x32. Verification stops reading `0xB8000` and
reconstructs text from the framebuffer by matching glyphs, locating the font
itself so a broken kernel-side discovery shows up as garbled text.

**Tech Stack:** Rust (`no_std`, nightly-2026-03-01, custom `x86_64-tuios` target),
`bootloader` 0.9.34, `x86_64` 0.15.2, ratatui, Python 3 for `tools/vgatext.py`,
QEMU + QMP for `make dump`.

**Spec:** `docs/superpowers/specs/2026-09-26-vga-1920x1080-design.md` — the spec
is binding over this plan.

## Global Constraints

- UI text in **Spanish**; command names follow Unix conventions.
- **Never panic.** Failures surface as Spanish messages or dialogs.
- VGA 80x25 / CP437 stay valid. Any glyph must remain drawable through
  `usr::tui::char_to_cp437`; the pixel sink reuses that conversion, so the
  repertoire is not extended. VGA stays CP437 and nothing else: no Unicode, no
  bundled fonts.
- Work on `main`. Never more than one task in progress.
- Conventional commits, **in English**.
- TDD: every new test must be **observed failing** before the code that makes it
  pass exists. Mind R54 — the harness is fail-fast and alphabetical, so stage
  production code so each test gets its own RED, and name tests that touch global
  state so they sort early.
- `make test` runs in release **and** in debug.

## Review Focus

Five input classes the spec implies that a test task below does not already
cover, most likely to bite first. Each line names the test to add, to the task
that owns the code.

1. **`display=1920x1080` but VBE offers nothing that large.** A quiet kernel
   renders the wrong size and the user blames the desktop. The boot message must
   name the mode actually obtained. → Task 3 adds
   `vbe_reports_the_mode_it_actually_got`.
2. **A VBE framebuffer base outside the identity-mapped first gigabyte.** The
   `map_physical_memory` feature makes the first gigabyte identity-mapped and
   nothing more, so a base at or above `0x4000_0000` cannot be mapped the same
   way. Mapping it anyway yields a page fault or silent garbage. → Task 5 adds
   `framebuffer_rejects_a_base_above_the_identity_window`.
3. **A framebuffer whose `stride` is not `width * 4`.** VBE pads rows, and
   rasterizing with `width` shears the whole screen while still looking almost
   right, which is the worst kind of bug. → Task 6 adds
   `blit_respects_a_padded_stride`.
4. **The last cell of the screen.** 119x32 at 16x32 in 1920x1080 ends exactly on
   the framebuffer edge, so a blit that writes one column too far corrupts memory
   past the framebuffer. → Task 6 adds `blit_at_the_last_cell_writes_no_further`.
5. **A cell whose foreground equals its background.** ratatui emits these, and
   the decoder's "most common colour is the background, the next is the
   foreground" rule degenerates when there is only one colour. The decoder should
   return a space, not garbage. → Task 9 adds
   `decode_a_single_colour_cell_is_a_space`.

```rust
//! Pure parsing of the two VBE data structures. No hardware, no BIOS: given the
//! bytes, produce the values. Everything here is testable in isolation, which is
//! why the mode enumeration lives in its own module.

/// One entry of the VBE mode info structure, already decoded.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ModeInfo {
    pub mode_number: u16,
    pub width: u16,
    pub height: u16,
    /// The row pitch VBE reports, in bytes. Not `width * 4`: modes are padded,
    /// and using a derived pitch shears the screen.
    pub bytes_per_line: u16,
    pub bpp: u8,
    pub phys_base_ptr: u32,
    /// Bit 14 of the attributes word: the mode has a linear framebuffer.
    pub has_lfb: bool,
}

fn le16(buf: &[u8], at: usize) -> u16 {
    u16::from_le_bytes([buf[at], buf[at + 1]])
}

fn le32(buf: &[u8], at: usize) -> u32 {
    u32::from_le_bytes([buf[at], buf[at + 1], buf[at + 2], buf[at + 3]])
}

/// Decode the 256-byte `VBE_INFO` block into the list of mode numbers it
/// advertises, stopping at the `0xFFFF` terminator.
pub fn parse_info_block(buf: &[u8]) -> Vec<u16> {
    let mut modes = Vec::new();
    let mut at = 8;
    while at + 2 <= 250 {
        let mode = le16(buf, at);
        if mode == 0xFFFF {
            break;
        }
        modes.push(mode);
        at += 2;
    }
    modes
}

/// Decode a 256-byte `VBE_MODE_INFO` block fetched for `mode_number`, or `None`
/// when the BIOS says the mode is not supported.
pub fn parse_mode_info(buf: &[u8], mode_number: u16) -> Option<ModeInfo> {
    let attrs = le16(buf, 0);
    if attrs & 1 == 0 {
        return None;
    }
    Some(ModeInfo {
        mode_number,
        width: le16(buf, 18),
        height: le16(buf, 20),
        bytes_per_line: le16(buf, 16),
        bpp: ((attrs >> 25) & 0x7) as u8,
        phys_base_ptr: le32(buf, 40),
        has_lfb: attrs & (1 << 14) != 0,
    })
}
```

```rust
//! Choosing a video mode. Pure, and a product rule rather than a protocol
//! detail: a requested resolution is a *preference*, because VBE is not
//! obliged to offer it. Whatever is picked has to be a mode the kernel can
//! actually use -- a linear framebuffer at 32 bits per pixel -- otherwise the
//! renderer would be writing into something it cannot address.

use super::parse::ModeInfo;

/// A mode the display can use: linear framebuffer, 32bpp.
fn usable(mode: &ModeInfo) -> bool {
    mode.has_lfb && mode.bpp == 32
}

/// The best mode for a `want` of `width` x `height`.
///
/// Modes that fit inside `want` are preferred, largest first. When nothing fits
/// -- the usual case, since VBE need not offer 1920x1080 -- the largest usable
/// mode wins instead, because a working screen at the wrong size beats no
/// screen. Ties on size go to the deeper mode.
pub fn select_mode(modes: &[ModeInfo], want: (u16, u16)) -> Option<ModeInfo> {
    let mut best: Option<ModeInfo> = None;

    for mode in modes.iter().filter(|m| usable(m)) {
        let fits = mode.width <= want.0 && mode.height <= want.1;
        let better = match best {
            None => true,
            Some(current) => {
                let current_fits = current.width <= want.0 && current.height <= want.1;
                // Anything that fits beats anything that does not.
                if fits != current_fits {
                    fits
                } else {
                    let area = mode.width as u32 * mode.height as u32;
                    let current_area = current.width as u32 * current.height as u32;
                    area > current_area || (area == current_area && mode.bpp > current.bpp)
                }
            }
        };
        if better {
            best = Some(*mode);
        }
    }

    best
}
```

And in `vbe/mod.rs`, add `pub mod select;` next to `pub mod parse;`.

- [ ] **Step 3: Write the V86 thunk**

`src/sys/vga/vbe/v86.s`. This is real-mode interrupt dispatch from long mode:
clear PE, load the v86 selector, build the register block, execute the
interrupt, expect a `#GP` to bounce control back, restore PE.

```asm
# v86.s — run one real-mode BIOS interrupt from long mode.
#
# The VBE entry points are `int 10h` handlers in real-mode code, so calling them
# from long mode means borrowing the CPU's virtual-808 mode. The sequence is
# fixed: leave protected mode, load the 0x33 selector, execute the interrupt,
# and expect a #GP the moment the BIOS tries to touch a segment we did not give
# it. The #GP handler is the normal way back, so the state is saved on the way
# in and the handler longjmps to the label below.
#
# In:  esi = pointer to a 32-bit-aligned register block in low memory
#      edi = interrupt vector to call (0x0010 for int 10h)
# Out: eax = 0 on success, 1 on failure (the BIOS is not there)

.section .text
.global v86_call
v86_call:
    # The #GP handler needs to know which vector we were calling, so record it
    # before anything can fault.
    mov [rel v86_vector], edi

    # Register block layout the BIOS expects: eax, ebx, ecx, edx, es, ds, fs,
    # gs, si, di, bp, sp, ip, cs, flags. esi points at its eip+cs+flags tail so
    # that writing a far pointer back there is a legal far return.
    mov word [rel v86_ret_ip], .Lv86_far_return
    mov word [rel v86_ret_cs], 0x0000
    pushf
    pop qword [rel v86_eflags]

    push rbx
    push rbp
    push r12
    push r13
    push r14
    push r15

    # Leave protected mode.
    mov rax, cr0
    and rax, ~(1 << 0)
    mov cr0, rax

    # Load the v86 monitor selector. QEMU and Bochs both honour 0x33.
    mov ax, 0x33
    mov es, ax

    # Fill the register block from the caller's rdi/rsi values.
    mov eax, [rel v86_saved_eax]
    mov [rsi + 0x00], eax
    mov [rsi + 0x04], ebx
    mov [rsi + 0x08], ecx
    mov [rsi + 0x0C], edx
    mov [rsi + 0x10], es
    mov [rsi + 0x12], ds
    mov [rsi + 0x14], fs
    mov [rsi + 0x16], gs
    mov [rsi + 0x18], rdi
    mov [rsi + 0x1A], rsi
    mov [rsi + 0x1C], rbp
    mov [rsi + 0x1E], rsp
    mov rax, [rel v86_eflags]
    mov [rsi + 0x20], rax

    # Enter v86 mode and call.
    mov eax, 0
    int 0x21
    jmp .Lv86_failed

.Lv86_far_return:
    # The BIOS returned through the far pointer we planted.
    mov eax, [rel v86_eflags]
    mov [rsi + 0x20], eax
    mov eax, [rsi + 0x00]
    mov [rel v86_saved_eax], eax
    mov ebx, [rsi + 0x04]
    mov ecx, [rsi + 0x08]
    mov edx, [rsi + 0x0C]

    pop r15
    pop r14
    pop r13
    pop r12
    pop rbp
    pop rbx

    # Back to protected mode.
    mov rax, cr0
    or rax, (1 << 0)
    mov cr0, rax
    xor eax, eax
    ret

.Lv86_failed:
    mov rax, cr0
    or rax, (1 << 0)
    mov cr0, rax
    pop r15
    pop r14
    pop r13
    pop r12
    pop rbp
    pop rbx
    mov eax, 1
    ret

.section .bss
.align 8
.global v86_vector
v86_vector:    .quad 0
.global v86_eflags
v86_eflags:    .quad 0
.global v86_saved_eax
v86_saved_eax: .quad 0
.align 2
v86_ret_ip:    .word 0
v86_ret_cs:    .word 0
```

```rust
//! The safe half of the V86 monitor. `call` is the only thing that touches the
//! thunk, and the register block it hands over is ordinary low memory, so the
//! unsafe is one call wide.

use core::arch::global_asm;

global_asm!(include_str!("v86.s"));

extern "Rust" {
    fn v86_call(regs: *mut V86Regs, vector: usize) -> usize;
}

/// The register block the BIOS reads and writes. Laid out as the 16-bit
/// segment the v86 monitor expects, then the 32-bit register values.
#[repr(C)]
pub struct V86Regs {
    pub eax: u32,
    pub ebx: u32,
    pub ecx: u32,
    pub edx: u32,
    pub es: u16,
    pub ds: u16,
    pub fs: u16,
    pub gs: u16,
    pub si: u16,
    pub di: u16,
    pub bp: u16,
    pub sp: u16,
    pub ip: u16,
    pub flags: u32,
}

/// The BIOS is not reachable, or it did not come back.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct V86Error;

/// Run one real-mode BIOS interrupt. `int 10h` is `vector` 0x0010.
pub fn call(regs: &mut V86Regs, vector: u16) -> Result<(), V86Error> {
    // The block must be in the first megabyte: the v86 monitor address space is
    // 16-bit-offset, and the BIOS writes a far return pointer into it.
    let addr = regs as *mut V86Regs as usize;
    if addr >= 0x0010_0000 {
        return Err(V86Error);
    }
    let status = unsafe { v86_call(regs, vector as usize) };
    if status == 0 {
        Ok(())
    } else {
        Err(V86Error)
    }
}
```

```rust
/// The mode the display will use, and the number to hand back to VBE.
#[derive(Debug, Clone, Copy)]

    pub mode_number: u16,

/// What the kernel says on the serial console about the mode it obtained.
pub fn describe(chosen: &Chosen) -> String {
    format!(

/// Enumerate VBE and choose a mode. The Spanish string on failure is what the
/// boot sequence prints before falling back to 80x25 text mode.
pub fn enumerate(want: (u16, u16)) -> Result<Chosen, &'static str> {
    // AX=4F00: the controller information block.
    let mut info = [0u8; 512];
    let mut regs = V86Regs { eax: 0x4F00, ..unsafe { core::mem::zeroed() } };
    regs.es = 0;
    v86::call(&mut regs, 0x0010).map_err(|_| "VBE no está disponible en esta máquina")?;
    let signature = u32::from_le_bytes([info[0], info[1], info[2], info[3]]);
    if signature != 0x5345_5345 {
        return Err("la BIOS no informa de VESA");
    }

    // AX=4F01 per mode: the mode information structure.
    let mut candidates = Vec::new();
    for number in parse::parse_info_block(&info) {
        let mut block = [0u8; 256];
        let mut regs = V86Regs { eax: 0x4F01, ..unsafe { core::mem::zeroed() } };
        regs.ebx = number as u32;
        regs.ecx = block.as_mut_ptr() as u32;
        regs.es = 0;
        if v86::call(&mut regs, 0x0010).is_err() {
            continue;
        }
        if let Some(mode) = parse::parse_mode_info(&block, number) {
            candidates.push(mode);
        }
    }

    let mode = select::select_mode(&candidates, want)
        .ok_or("ningún modo de VBE con framebuffer lineal a 32 bpp")?;

    // AX=4F02: actually set it. Nothing before this point changed the hardware;
    // the framebuffer is only real once the BIOS has been told.
    let mut regs = V86Regs { eax: 0x4F02, ..unsafe { core::mem::zeroed() } };
    regs.ebx = mode.mode_number as u32;
    v86::call(&mut regs, 0x0010).map_err(|_| "VBE no aceptó el modo elegido")?;

    let mode_number = mode.mode_number;
    Ok(Chosen { mode, mode_number })
}
```

```rust
//! The 8x16 CP437 font, found by scanning the VGA BIOS ROM.
//!
//! The conventional address is wrong. "INT 1Fh points at 0xC1000" does not hold
//! here: measured, 0xC1000 holds BIOS machine code, and the BDA word at 0x449
//! is a far pointer to nothing useful. The table is at 0xC6720 on this machine,
//! but that is where *this* BIOS put it, so it is located by scanning and
//! anchored on a glyph whose bytes are known, then validated.

/// The IBM VGA 8x16 `A`, one bit per pixel, MSB leftmost. The scan anchor.
pub const GLYPH_A_8X16: [u8; 16] = [
    0x00, 0x00, 0x10, 0x38, 0x6C, 0xC6, 0xC6, 0xFE, 0xC6, 0xC6, 0xC6, 0xC6, 0x00, 0x00, 0x00,
    0x00,
];

/// The VGA BIOS ROM window, which the option ROM is mapped into.
pub const ROM_START: usize = 0x000C_0000;
pub const ROM_SIZE: usize = 0x0000_8000;

/// 256 glyphs, 16 wide, 32 tall, one byte per pixel.
pub const CELLS_16X32: usize = 256 * 16 * 32;

const TABLE_8X16: usize = 256 * 16;

/// A table is only a table if its space is blank. No real font inks it, so an
/// inked space means the anchor was a coincidence in unrelated bytes.
fn valid_at(rom: &[u8], table: usize) -> bool {
    if table + TABLE_8X16 > rom.len() {
        return false;
    }
    rom[table + 0x20 * 16..table + 0x21 * 16].iter().all(|b| *b == 0)
        && rom[table + 0x41 * 16..table + 0x42 * 16] == GLYPH_A_8X16
}

/// Byte offset of the 8x16 CP437 table inside `rom`, or `None`.
pub fn find_in(rom: &[u8]) -> Option<usize> {
    rom.windows(16)
        .position(|window| window == GLYPH_A_8X16)
        .and_then(|at| {
            let table = at.checked_sub(0x41 * 16)?;
            valid_at(rom, table).then_some(table)
        })
}

/// The same, over the live VGA ROM window.
pub fn find() -> Option<usize> {
    let base = phys_to_ptr(ROM_START);
    // SAFETY: the option ROM is mapped read-only at a fixed window, and we read
    // exactly ROM_SIZE bytes of it, which the window is by definition.
    let rom = unsafe { core::slice::from_raw_parts(base, ROM_SIZE) };
    find_in(rom).map(|offset| ROM_START + offset)
}

/// 8x16 to 16x32, one byte per pixel, nearest-neighbour. Lossless: a 1-bit
/// bitmap scaled by two is still 1-bit, just chunkier.
pub fn upscale(src: &[u8; TABLE_8X16], dst: &mut [u8; CELLS_16X32]) {
    for glyph in 0..256 {
        for row in 0..16 {
            let bits = src[glyph * 16 + row];
            for bit in 0..8 {
                let value = if bits & (0x80 >> bit) != 0 { 0xFF } else { 0x00 };
                for dy in 0..2 {
                    let y = glyph * 16 * 32 + (row * 2 + dy) * 16 + bit * 2;
                    dst[y] = value;
                    dst[y + 1] = value;
                }
            }
        }
    }
}
```

```rust
//! Mapping the linear framebuffer, and telling the dump tool where it is.
//!
//! The tool used to read the 80x25 text buffer at a fixed address. There is no
//! equivalent fixed address for a linear framebuffer, so the kernel publishes
//! the geometry it chose and the tool reads it back. The struct carries a magic
//! so a wrong address is a loud failure and not a plausible-looking misread.

/// A page below 1 MB: identity-mapped by the boot path, and below the kernel at
/// 1 MB. It is explicitly reserved in the memory map so the allocator never
/// hands it out.
pub const DISPLAY_INFO_PHYS: usize = 0x0006_0000;
/// `"DISO"` little-endian.
pub const DISPLAY_INFO_MAGIC: u32 = 0x4F53_4944;
/// 11 little-endian u64 words. The host parses this layout, so it is fixed.
pub const DISPLAY_INFO_LEN: usize = 11 * 8;
/// The first gigabyte is identity-mapped by `map_physical_memory`; nothing
/// above it is, so a framebuffer at 4 GiB cannot be mapped the same way.
const IDENTITY_WINDOW: usize = 0x4000_0000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(C)]
pub struct DisplayInfo {
    pub magic: u32,
    pub fb_phys: u64,
    pub width: u32,
    pub height: u32,
    pub stride: u32,
    pub bpp: u32,
    pub cell_w: u32,
    pub cell_h: u32,
    pub cols: u32,
    pub rows: u32,
    pub font_phys: u64,
}

impl DisplayInfo {
    /// The eleven words, in declaration order, little-endian.
    fn words(&self) -> [u64; 11] {
        [
            self.magic as u64,
            self.fb_phys,
            self.width as u64,
            self.height as u64,
            self.stride as u64,
            self.bpp as u64,
            self.cell_w as u64,
            self.cell_h as u64,
            self.cols as u64,
            self.rows as u64,
            self.font_phys,
        ]
    }

    pub fn to_bytes(&self) -> [u8; DISPLAY_INFO_LEN] {
        let mut out = [0u8; DISPLAY_INFO_LEN];
        for (n, word) in self.words().iter().enumerate() {
            out[n * 8..n * 8 + 8].copy_from_slice(&word.to_le_bytes());
        }
        out
    }

    pub fn from_bytes(bytes: &[u8]) -> Option<Self> {
        if bytes.len() < DISPLAY_INFO_LEN {
            return None;
        }
        // Read through the same `words` order, so the two halves cannot drift.
        let mut words = [0u64; 11];
        for (n, word) in words.iter_mut().enumerate() {
            *word = u64::from_le_bytes(
                bytes[n * 8..n * 8 + 8].try_into().expect("slice is 8 bytes"),
            );
        }
        let info = Self {
            magic: words[0] as u32,
            fb_phys: words[1],
            width: words[2] as u32,
            height: words[3] as u32,
            stride: words[4] as u32,
            bpp: words[5] as u32,
            cell_w: words[6] as u32,
            cell_h: words[7] as u32,
            cols: words[8] as u32,
            rows: words[9] as u32,
            font_phys: words[10],
        };
        (info.magic == DISPLAY_INFO_MAGIC).then_some(info)
    }
}

/// A mapped linear framebuffer, as 32-bit pixels.
pub struct Frame {
    pub ptr: *mut u32,
    pub width: u32,
    pub height: u32,
    /// Bytes per row, which VBE pads and which is not `width * 4`.
    pub stride: u32,
}

/// Map a chosen mode's framebuffer and publish the geometry.
pub fn map(chosen: &vbe::Chosen) -> Result<Frame, &'static str> {
    let base = chosen.mode.phys_base_ptr as usize;
    if base == 0 || base >= IDENTITY_WINDOW {
        return Err("el framebuffer está fuera del rango mapeado");
    }
    if chosen.mode.bytes_per_line == 0 {
        return Err("VBE no informó del paso de línea");
    }

    // Map every page the framebuffer covers. The first gigabyte is already
    // identity-mapped by the boot path, but doing it through the mapper keeps
    // this correct if that ever stops being true, and it is what marks the pages
    // present and writable.
    let bytes = chosen.mode.bytes_per_line as usize * chosen.mode.height as usize;
    // SAFETY: the page table comes from CR3, and the mapper holds it exclusively
    // for the duration of the loop.
    let mut mapper = unsafe { crate::sys::mem::mapping::create_mapper(
        crate::sys::mem::paging::active_page_table(),
    ) };
    for page in (base..base + bytes).step_by(4096) {
        use x86_64::structures::paging::{Mapper, Page, PageTableFlags};
        use x86_64::addr::VirtAddr;
        // SAFETY: identity mapping, so the physical address is also the virtual.
        let target = unsafe { Page::from_phys_addr(VirtAddr::new(page as u64).into()) }
            .map_err(|_| "no se pudo mapear el framebuffer")?;
        let flags = PageTableFlags::PRESENT | PageTableFlags::WRITABLE;
        // SAFETY: `target` is a valid page in the identity-mapped range and is
        // not already mapped by anything we own.
        unsafe {
            mapper.map(target, flags).map_err(|_| "no se pudo mapear el framebuffer")?;
        }
    }
    drop(mapper);

    let info = DisplayInfo {
        magic: DISPLAY_INFO_MAGIC,
        fb_phys: base as u64,
        width: chosen.mode.width as u32,
        height: chosen.mode.height as u32,
        // VBE's own pitch. Deriving `width * 4` is the bug this avoids.
        stride: chosen.mode.bytes_per_line as u32,
        bpp: chosen.mode.bpp as u32,
        cell_w: 16,
        cell_h: 32,
        cols: chosen.mode.width as u32 / 16,
        rows: chosen.mode.height as u32 / 32,
        font_phys: 0,
    };
    publish(info);

    Ok(Frame { ptr: base as *mut u32, width: info.width, height: info.height, stride: info.stride })
}

/// Write the struct where the dump tool looks for it.
fn publish(info: DisplayInfo) {
    let bytes = info.to_bytes();
    // SAFETY: the page is below 1 MB, identity-mapped, and reserved from the
    // allocator in `sys::mem`, so nothing else owns it.
    unsafe {
        core::ptr::copy_nonoverlapping(
            bytes.as_ptr(),
            DISPLAY_INFO_PHYS as *mut u8,
            DISPLAY_INFO_LEN,
        );
    }
}
```

```rust
/// production. Writes outside the buffer panic rather than corrupting memory,
/// which is what turns "wrote one column too far" from a heap corruption into
/// a test failure.
struct TestFrame {
    buffer: &'static mut [u32],
    frame: Frame,
}

impl TestFrame {
    fn new(width: u16, height: u16, stride: u32) -> Self {
        let len = (stride as usize / 4) * height as usize;
        let buffer: &'static mut [u32] = Box::leak(vec![0; len].into_boxed_slice());
        let ptr = buffer.as_mut_ptr();
        Self {
            buffer,
            frame: Frame { ptr, width: width as u32, height: height as u32, stride },
        }
    }

    fn at(&self, x: u16, y: u16) -> u32 {
        let at = y as usize * self.frame.stride as usize / 4 + x as usize;
        assert!(at < self.buffer.len(), "read out of frame: ({x}, {y})");
        self.buffer[at]
    }
```

```rust
//! The pixel sink: ratatui cells turned into glyphs in a linear framebuffer.
//!
//! The cell grid is 16x32, an 8x16 CP437 bitmap doubled in both directions. It
//! is drawn from the same `char_to_cp437` translation the text mode uses, so
//! the repertoire is exactly what it always was.

use ratatui::layout::Rect;

use crate::sys::vga::fontrom::CELLS_16X32;
use crate::sys::vga::framebuffer::Frame;
use crate::sys::vga::TUIOS_COLORS;

pub const CELL_W: u16 = 16;
pub const CELL_H: u16 = 32;

/// A doubled 8x16 font table: 256 glyphs of 16x32, one byte per pixel.
pub type Font16x32 = Box<[u8; CELLS_16X32]>;

/// Allocate a zeroed font on the heap.
///
/// `Box::new([0u8; CELLS_16X32])` looks like it allocates, but Rust builds the
/// array on the stack and then moves it, and 128 KiB does not fit in a 64-page
/// kernel stack. `new_zeroed` asks the allocator for zeroed memory and never
/// materialises a stack temporary.
pub fn allocate_font() -> Font16x32 {
    // SAFETY: `CELLS_16X32` is non-zero, and the global allocator is the
    // project's own, which is live by the time the display is initialised.
    unsafe { Box::new_zeroed() }
}

/// The 16 brand colours as `0x00RRGGBB`.
pub fn palette() -> [u32; 16] {
    let mut out = [0u32; 16];
    for (n, (r, g, b)) in TUIOS_COLORS.iter().enumerate() {
        out[n] = ((*r as u32) << 16) | ((*g as u32) << 8) | *b as u32;
    }
    out
}

/// Draw one glyph into one cell. Anything outside the framebuffer is skipped
/// rather than written, because a desktop that is briefly smaller than it
/// thinks should clip, not corrupt memory.
pub fn blit_glyph(
    frame: &mut Frame,
    col: u16,
    row: u16,
    glyph: u8,
    fg: u32,
    bg: u32,
    font: &[u8; CELLS_16X32],
) {
    let origin_x = col as u32 * CELL_W as u32;
    let origin_y = row as u32 * CELL_H as u32;
    if origin_x >= frame.width || origin_y >= frame.height {
        return;
    }

    for y in 0..CELL_H as u32 {
        let screen_y = origin_y + y;
        if screen_y >= frame.height {
            break;
        }
        let glyph_row = glyph as u32 * CELL_H as u32 * CELL_W as u32 + y * CELL_W as u32;
        for x in 0..CELL_W as u32 {
            let screen_x = origin_x + x;
            if screen_x >= frame.width {
                break;
            }
            let lit = font[(glyph_row + x) as usize] != 0;
            let colour = if lit { fg } else { bg };
            // SAFETY: both bounds are checked above, and `stride` is the row
            // pitch, which may exceed `width` in pixels.
            unsafe {
                let at = frame.ptr.add(screen_y as usize * frame.stride as usize / 4 + screen_x as usize);
                at.write_volatile(colour);
            }
        }
    }
}

/// The software cursor: an underline on the bottom scanlines of its cell.
///
/// Graphics mode has no hardware cursor, and the terminal shows the insertion
/// point only through this, so it is drawn and erased explicitly rather than
/// left to blink on its own. Blinking is out of scope; a solid block under the
/// glyph is what the text mode's cursor looked like anyway.
pub fn draw_cursor(
    frame: &mut Frame,
    col: u16,
    row: u16,
    colour: u32,
    _font: &[u8; CELLS_16X32],
) {
    let height = 4u32; // the bottom quarter of a 32-pixel cell
    let y0 = row as u32 * CELL_H as u32 + CELL_H as u32 - height;
    fill_pixels(frame, col as u32 * CELL_W as u32, y0, CELL_W as u32, height, colour);
}

/// Put the cell's background back. The backend redraws the glyph underneath,
/// so erasing only has to restore the background colour.
pub fn erase_cursor(
    frame: &mut Frame,
    col: u16,
    row: u16,
    background: u32,
    _font: &[u8; CELLS_16X32],
) {
    let height = 4u32;
    let y0 = row as u32 * CELL_H as u32 + CELL_H as u32 - height;
    fill_pixels(frame, col as u32 * CELL_W as u32, y0, CELL_W as u32, height, background);
}

/// A clipped run of pixels, which is the one primitive the other two need.
fn fill_pixels(frame: &mut Frame, x: u32, y: u32, width: u32, height: u32, colour: u32) {
    for dy in 0..height {
        let py = y + dy;
        if py >= frame.height {
            break;
        }
        for dx in 0..width {
            let px = x + dx;
            if px >= frame.width {
                break;
            }
            // SAFETY: both bounds are checked above.
            unsafe {
                frame
                    .ptr
                    .add(py as usize * frame.stride as usize / 4 + px as usize)
                    .write_volatile(colour);
            }
        }
    }
}

/// Fill a rectangle with one colour, clipped to the framebuffer.
pub fn fill_rect(frame: &mut Frame, rect: Rect, colour: u32) {
    for y in rect.y..rect.y.saturating_add(rect.height) {
        for x in rect.x..rect.x.saturating_add(rect.width) {
            if x < frame.width as u16 && y < frame.height as u16 {
                // SAFETY: bounds checked immediately above.
                unsafe {
                    frame
                        .ptr
                        .add(y as usize * frame.stride as usize / 4 + x as usize)
                        .write_volatile(colour);
                }
            }
        }
    }
}
```

```rust
//! Where a rendered cell goes. One enum, two destinations, so the rest of the
//! backend -- including ratatui's diffing -- is written once.

use ratatui::layout::Size;

use super::pixels;
use crate::sys::vga::fontrom::CELLS_16X32;
use crate::sys::vga::framebuffer::Frame;
use pixels::Font16x32;

pub enum Sink {
    /// The original 80x25 VGA text buffer at 0xB8000.
    Text { cols: u16, rows: u16 },
    /// A linear framebuffer with a 16x32 cell grid.
    Pixels { frame: Frame, font: Font16x32, cursor_on: bool },
}

impl Sink {
    pub fn text() -> Self {
        Sink::Text { cols: 80, rows: 25 }
    }

    pub fn pixels(frame: Frame, font: Font16x32) -> Self {
        Sink::Pixels { frame, font, cursor_on: true }
    }

    pub fn size(&self) -> Size {
        match self {
            Sink::Text { cols, rows } => Size::new(*cols, *rows),
            Sink::Pixels { frame, .. } => Size::new(
                (frame.width / pixels::CELL_W as u32) as u16,
                (frame.height / pixels::CELL_H as u32) as u16,
            ),
        }
    }

    pub fn pixel_size(&self) -> Size {
        match self {
            Sink::Text { .. } => Size::new(720, 400),
            Sink::Pixels { frame, .. } => Size::new(frame.width as u16, frame.height as u16),
        }
    }

    pub fn is_pixels(&self) -> bool {
        matches!(self, Sink::Pixels { .. })
    }
}
```

```rust
/// The result of asking for a pixel display: either a framebuffer we can draw
/// on, or the 80x25 text mode with the Spanish reason we ended up there.
pub enum Display {
    Pixels { sink: Sink, chosen: vbe::Chosen },
    Text { reason: &'static str },
}

impl Display {
    pub fn size(&self) -> Size {
        match self {
            Display::Pixels { sink, .. } => sink.size(),
            Display::Text { .. } => Size::new(80, 25),
        }
    }

    pub fn is_text(&self) -> bool {
        matches!(self, Display::Text { .. })
    }

    pub fn fallback_reason(&self) -> Option<&'static str> {
        match self {
            Display::Text { reason } => Some(reason),
            Display::Pixels { .. } => None,
        }
    }
}

/// Put the hardware back in 80x25. Anything that changed the video mode must be
/// able to undo it, or a later test inherits a screen it did not ask for.
pub fn restore_text_mode() {
    // The boot path's own routine, the one `set_text_mode` already calls.
    vga::set_text_mode();
}

/// The geometry of the text mode, as a test can observe it.
pub fn text_mode_size() -> Size {
    Size::new(80, 25)

/// Copy a font table out of the option ROM window into ordinary RAM.
///
/// The ROM window is device memory that may be read-triggered, and the upscale
/// writes 128 KiB of output. Doing the read once into a stack buffer means every
/// later touch is plain RAM.
fn read_rom_table(physical: usize) -> [u8; 4096] {
    let mut out = [0u8; 4096];
    // SAFETY: the option ROM is mapped read-only across a 32 KiB window, and this
    // copies exactly the 4096 bytes that `find` validated as a font table.
    unsafe {
        core::ptr::copy_nonoverlapping(physical as *const u8, out.as_mut_ptr(), out.len());
    }
    out
}

/// Ask for a `want` x `want` pixel display. Any failure downgrades to text mode
/// with a reason, because a smaller working screen beats no screen.
pub fn init_display(want: (u16, u16)) -> Display {
    let chosen = match vbe::enumerate(want) {
        Ok(chosen) => chosen,
        Err(reason) => {
            log!("{reason}");
            return Display::Text { reason };
        }
    };
    let frame = match framebuffer::map(&chosen) {
        Ok(frame) => frame,
        Err(reason) => {
            log!("{reason}");
            return Display::Text { reason };
        }
    };
    let Some(table) = fontrom::find() else {
        let reason = "no se encontró una fuente 8x16 en la ROM VGA";
        log!("{reason}");
        return Display::Text { reason };
    };

    let mut font = pixels::allocate_font();
    fontrom::upscale(&read_rom_table(table), &mut font);
    framebuffer::publish_font(table);

    log!("{}", vbe::describe(&chosen));
    Display::Pixels { sink: Sink::pixels(frame, font), chosen }
}
```

### Task 9: Reconstruct the text from the pixels

The safety net. This is the part that has caught real bugs in this project, so it
is not optional and it is not allowed to become a shadow-buffer reader: it finds
the font itself, so a kernel-side discovery failure shows up as garbled text

```python
def synthetic_font():
    """A CP437-shaped 8x16 table for the decoder tests.

    It does not have to be the BIOS's font. What the decoder has to do is match
    pixels to glyphs, and a table where every glyph has a distinct pattern tests
    that just as well -- and it can be built here instead of shipping a binary.

    Two invariants are load-bearing and are asserted below: the space is blank
    (that is what the scan and the background detection both rely on) and no two
    glyphs share a pattern (otherwise a match is ambiguous).
    """
    font = bytearray(256 * 16)
    for glyph in range(256):
        if glyph == 0x20:
            continue  # space stays blank
        for row in range(16):
            # A distinct 8-bit pattern per glyph, never all zero.
            font[glyph * 16 + row] = ((glyph * 7 + row * 13) & 0xFF) | 0x01
    return bytes(font)


FONT_8X16 = synthetic_font()
FONT = vgatext.double_font(FONT_8X16)

# The handful of Unicode characters the tests render, and their CP437 codes.
# Deliberately not the full table: the point is to exercise the decoder, and the
# full map lives in one place on the Rust side.
CP437_OF = {" ": 0x20, "ñ": 0xA0, "┌": 0xDA, "─": 0xC4, "┐": 0xBF,
            "▸": 0x10, "█": 0xDB, "░": 0xB0, "▓": 0xB2,
            "←": 0x1B, "↑": 0x18, "a": 0x61}

        # passing for the wrong reason.

    def test_the_test_font_gives_every_glyph_a_distinct_pattern(self):
        patterns = {FONT_8X16[g * 16:g * 16 + 16] for g in range(256)}
        self.assertEqual(len(patterns), 256, "two glyphs share a pattern")


def display_info(cols, rows, cell_w=16, cell_h=32):
    return vgatext.DisplayInfo(
        fb_phys=0xFD000000, width=cols * cell_w, height=rows * cell_h,

def render_cells(chars, font, info):
    """Draw `chars` the way the kernel would, so the decoder can read it back."""
    bg = np.array([0x0C, 0x0C, 0x10], dtype=np.uint8)   # palette index 0
    fg = np.array([0xBC, 0xC4, 0xCC], dtype=np.uint8)   # palette index 7
    fb = np.empty((info.height, info.width, 3), dtype=np.uint8)
    fb[:] = bg
    for col, ch in enumerate(chars):
        block = font[CP437_OF.get(ch, 0x20)]
        xs = slice(col * info.cell_w, (col + 1) * info.cell_w)
        fb[0:info.cell_h, xs] = np.where(block[:, :, None], fg, bg)
    return fb


class DecodeTests(unittest.TestCase):
    def test_a_single_colour_cell_is_a_space(self):

        # colour is the background, the next is the foreground" degenerates when
        # there is only one colour. The answer is a space, not garbage.
        fb = np.zeros((32, 16, 3), dtype=np.uint8)
        info = display_info(cols=1, rows=1)
        self.assertEqual(vgatext.decode(fb, info, FONT), [" "])

        # R15's CP437 story has to survive the pixel path: the accented glyphs

    def test_decodes_every_cp437_glyph_the_desktop_uses(self):

        # has to be a *distinct* CP437 code -- '▸' and '▶' are both 0x10 in

        text = "┌─┐▸█░▓←↑"
        fb = render_cells(list(text), FONT, info := display_info(cols=len(text), rows=1))
```

```python
# numpy is a new host dependency for this tool. It is here because decoding
# 8.3 million pixels one byte at a time takes minutes, and the whole point of
# the pixel path is that verification stays fast enough to run every time.
try:
    import numpy as np
except ImportError:  # pragma: no cover
    sys.exit("vgatext: hace falta numpy (pip install numpy) para leer pixeles")

DISPLAY_INFO_PHYS = 0x00060000
DISPLAY_INFO_LEN = 88  # 11 little-endian u64 words; must match DisplayInfo::to_bytes
DISPLAY_INFO_MAGIC = 0x4F534944  # "DISO"

# The IBM VGA 8x16 'A', byte for byte. The host scans for the font itself, with
# the same anchor the kernel uses, so a kernel that found the wrong table shows
# up as garbled text instead of being quietly agreed with.
GLYPH_A_8X16 = bytes([
    0x00, 0x00, 0x10, 0x38, 0x6C, 0xC6, 0xC6, 0xFE,
    0xC6, 0xC6, 0xC6, 0xC6, 0x00, 0x00, 0x00, 0x00,
])
ROM_START, ROM_SIZE = 0x000C0000, 0x00008000


class DisplayInfoError(RuntimeError):
    """The published display struct is not readable, so nothing can be trusted."""


class GeometryError(RuntimeError):
    """The framebuffer is not the size the kernel said it was."""


@dataclass
class DisplayInfo:
    fb_phys: int
    width: int
    height: int
    stride: int
    bpp: int
    cell_w: int
    cell_h: int
    cols: int
    rows: int
    font_phys: int

    @classmethod
    def from_bytes(cls, data):
        if len(data) < DISPLAY_INFO_LEN:
            raise DisplayInfoError(
                f"solo {len(data)} bytes de informacion de pantalla, "
                f"hacen falta {DISPLAY_INFO_LEN}: el kernel no la publico"
            )
        words = struct.unpack("<11Q", data[:DISPLAY_INFO_LEN])
        if words[0] != DISPLAY_INFO_MAGIC:
            raise DisplayInfoError(
                f"magic de pantalla {words[0]:#x}, se esperaba "
                f"{DISPLAY_INFO_MAGIC:#x}: la direccion no es la del struct"
            )
        return cls(
            fb_phys=words[1], width=words[2], height=words[3], stride=words[4],
            bpp=words[5], cell_w=words[6], cell_h=words[7],
            cols=words[8], rows=words[9], font_phys=words[10],
        )


def find_font(rom):
    """Byte offset of the 8x16 CP437 table, or None. Mirrors fontrom::find_in."""
    at = 0
    while True:
        at = rom.find(GLYPH_A_8X16, at)
        if at < 0:
            return None
        table = at - 0x41 * 16
        if table >= 0 and not any(rom[table + 0x20 * 16:table + 0x21 * 16]):
            return table
        at += 1


def double_font(font_8x16):
    """256 glyphs of 8x16 into 256 glyphs of 16x32, as a (256, 32, 16) bool mask."""
    out = np.zeros((256, 32, 16), dtype=bool)
    for glyph in range(256):
        for row in range(16):
            bits = font_8x16[glyph * 16 + row]
            for bit in range(8):
                out[glyph, row * 2:row * 2 + 2, bit * 2:bit * 2 + 2] = (
                    bits >> (7 - bit)) & 1 == 1
    return out


def decode(fb, info, font):
    """Reconstruct the text from the pixels. Returns one string per row.

    `fb` is a (height, width, 3) array of the palette colours. A cell's
    background is its most common colour and its foreground the next most
    common; a cell with a single colour is a space.
    """
    if fb.shape[0] != info.height or fb.shape[1] != info.width:
        raise GeometryError(
            f"el framebuffer mide {fb.shape[1]}x{fb.shape[0]} y el kernel dijo "
            f"{info.width}x{info.height}"
        )
    # Matched once for the whole screen, not per cell: 3960 cells against 256
    # glyphs is 15 million comparisons if done naively.
    rows = []
    for row in range(info.rows):
        chars = []
        for col in range(info.cols):
            block = fb[
                row * info.cell_h:(row + 1) * info.cell_h,
                col * info.cell_w:(col + 1) * info.cell_w,
            ]
            colours, counts = np.unique(block.reshape(-1, 3), axis=0,
                                        return_counts=True)
            if len(colours) < 2:
                chars.append(" ")
                continue
            order = counts.argsort()
            background = colours[order[-1]]
            fg = colours[order[-2]]
            mask = np.all(block == fg, axis=2)
            hits = np.flatnonzero((font == mask[None, :, :]).all(axis=(1, 2)))
            if hits.size == 0:
                # No glyph matches, so the cell is not text we can name. `argmax`
                # would silently return glyph 0 and print a null character, which
                # is how a broken renderer turns into a screen of nothing.
                chars.append(" ")
            else:
                chars.append(BLOCK_TO_UNICODE.get(int(hits[0]), " "))
        rows.append("".join(chars).rstrip())
    return rows
```

`BLOCK_TO_UNICODE` is the same table `char_to_cp437` implements, read out of it
so there is exactly one list of glyphs in the project.
